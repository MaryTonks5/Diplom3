# Дипломный проект. Часть 3 — UI-тесты для Stellar Burgers

## 📝 Описание проекта
Проект содержит автоматизированные UI-тесты для веб-сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/). Тесты покрывают ключевой функционал: регистрацию пользователей, вход в систему и работу с конструктором бургеров.

## 🛠 Технологии и инструменты

| Технология          | Версия   | Назначение |
|---------------------|----------|------------|
| Java                | 11       | Язык программирования |
| JUnit 4             | 4.13.2   | Фреймворк для тестирования |
| Maven               | 3.9.9    | Сборка проекта и управление зависимостями |
| Selenium WebDriver  | 4.x      | Автоматизация браузера |
| Allure              | 2.29.0   | Генерация отчетов о тестировании |
| Lombok              | 1.18.24  | Упрощение кода (геттеры, сеттеры) |
| WebDriverManager    | 5.x      | Автоматическое управление драйверами браузеров |


## ✅ Функциональность, покрытая тестами

### 1. Тесты конструктора (`ConstructorTest`)
*Проверка переключения между разделами конструктора бургеров:*
*   Переход к разделу **«Булки»**
*   Переход к разделу **«Соусы»**
*   Переход к разделу **«Начинки»**

### 2. Тесты входа в систему (`LoginTest`)
*Проверка различных способов авторизации:*
*   Вход по кнопке **«Войти в аккаунт»** на главной странице
*   Вход через кнопку **«Личный кабинет»** в хедере
*   Вход через ссылку **«Войти»** на странице регистрации
*   Вход через ссылку **«Войти»** на странице восстановления пароля

### 3. Тесты регистрации (`RegistrationTest`)
*Проверка валидации пароля при регистрации:*
*   ✅ Успешная регистрация с паролем **6 и более символов**
*   ❌ Ошибка регистрации с паролем **менее 6 символов**

## 🚀 Запуск тестов

### Предварительные требования
- Установленная Java 11
- Установленный Maven
- Браузер (Chrome или Яндекс.Браузер)

### Команды для запуска

```bash
# Очистка и сборка проекта
mvn clean compile

# Запуск всех UI-тестов
mvn clean test

# Запуск конкретного тестового класса
mvn clean test -Dtest=LoginTest
mvn clean test -Dtest=ConstructorTest
mvn clean test -Dtest=RegistrationTest

# Запуск тестов с выбором браузера (по умолчанию Chrome)
mvn clean test -Dbrowser=chrome
mvn clean test -Dbrowser=yandex
